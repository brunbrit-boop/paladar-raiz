# Paladar Raiz - Culinária Caipira & Marmitas Artesanais

Landing page moderna e aconchegante para o restaurante **Paladar Raiz**, unindo a apresentação da Chef Maria Rosa à venda e catálogo interativo de kits de marmitas congeladas artesanais.

## 🌿 Funcionalidades
- **Apresentação da Chef**: Trajetória, conceito "do campo à mesa" e os 4 pilares gastronômicos.
- **Cardápio Interativo**: Kits semanais, clássicos da roça, linha equilíbrio e doces caseiros.
- **Carrinho de Compras em Tempo Real**: Adição de itens, contadores e cálculo de totais.
- **Checkout com WhatsApp**: Envio automático do pedido formatado com pratos, endereço e dia de entrega.
- **Área dos Bastidores da Chef**: Acesso administrativo para gerenciamento de fotos, pratos e promoções.

## 🚀 Tecnologias
- HTML5 Semântico & Moderno
- CSS3 Vanilla com Design System rústico-chic responsivo
- JavaScript Vanilla com persistência em `localStorage`

## 📦 Como Rodar Localmente
Basta abrir o arquivo `index.html` em qualquer navegador ou rodar:
```bash
python -m http.server 3000
```
Acesse em: `http://localhost:3000`
